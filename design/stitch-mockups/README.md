# Google Stitch 초기 디자인 목업

INSIGHT UI(`src/`)를 설계할 때 출발점으로 삼은 Google Stitch 생성 목업입니다. 런타임에서 import·로드되지 않으며 시각 참조용으로만 보존합니다. 목업 속 문구(예: Huntington 위험도, 의사 사진·이름)는 Stitch 예시 데이터이며 실제 앱의 기능·데이터가 아닙니다.

- `clinical_diagnostic_precision/` — 색상·타이포그래피·간격 디자인 토큰(`DESIGN.md`)
- `clinical_doctor_portrait_photo_dr._kim_senior_neurologist_at_university/` — 헤더용 임상의 프로필 이미지 시안
- `insight_clinical_dashboard/` — 임상 의사결정 지원 대시보드(트리아지·모델 보정 상태) 화면
- `insight_clinical_logo/` — INSIGHT 로고 시안
- `insight_examination_history_registry/` — 전체 검사 이력·종단 레지스트리 화면
- `insight_patient_directory/` — 환자 관리·스크리닝 레지스트리 화면
- `insight_patient_voice_ai_screening_detail/` — 환자 음성 AI 스크리닝 결과 상세 화면
