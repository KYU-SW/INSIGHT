# 실험 결과 정리 및 검증

분류 실험은 비교군을 포함해 26개, 별도 분석 작업은 3개입니다. 동일 방법의 시드, 층 선택, 하이퍼파라미터, 반복 실행은 같은 실험의 변형으로 보존했습니다. 서로 다른 결과 파일은 중복처럼 보여도 삭제하지 않았습니다.

| 실험군 | 케이스 |
|---|---|
| 기존 ML 6개 | M0 Majority, M1 ElasticNet, M2 GlobalXGB, M3 TaskConcatXGB, M4 TaskStackXGB, M5 M1-M4 Fusion |
| WavLM 1개 | Frozen WavLM + ElasticNet |
| HuBERT 풀링 6개 | MLP/CNN 각각 mean, max, mean+std |
| 융합 추가 구조 5개 | Concat, CoAttention, Late3, Early3, EarlyHuBERTonly |
| 최신 개선 7개 | EXP01 Layer-weighted, EXP02 Attentive statistics, EXP03 Gated fusion, EXP04 Focal loss, EXP05 MIL, EXP06 Latent SpecAugment, EXP07 LoRA |
| 과거 Data2Vec 1개 | Data2Vec Audio Base. 대응 노트북은 제공 폴더에서 발견되지 않음 |

Baseline은 HuBERT max + MLP와 동일 계열이므로 풀링 실험과 중복 계산하지 않았습니다. 최신 BASE00/BASE01은 같은 구조의 원 설정/HPO 변형으로 함께 묶었습니다. 과거 ML 1·2차는 같은 모델 계열의 평가·보정 프로토콜 변형을 함께 보존하며, 위 개수는 모델 방법 기준입니다. M0는 다수 클래스 비교군입니다.

분석 작업 3개: 초기 음성 특징 분석, Analyze 통계 분석, eGeMAPS 그룹 비교. 통계 분석은 분류 실험 개수에 포함하지 않았습니다.

## 보존 방식

압축파일들을 같은 위치에 풀면 내부의 실험별 경로가 합쳐집니다. 원본 노트북의 코드·출력과 엑셀의 시트·수치·수식·서식·숨김 상태·그림을 그대로 보존했습니다. 원본 파일을 재저장하거나 수치를 다시 반올림하지 않았습니다. 통합 엑셀과 비교 그림·예측표는 shared_originals/00_통합원본에 온전히 남겼습니다. 최신 7개 실험의 모델·시드 결과는 각각의 케이스 묶음에 있습니다. 노트북과 엑셀은 별도 개별 복사본도 제공합니다.

원본 노트북의 저장 경로는 기록 보존을 위해 수정하지 않았습니다. 정리본에서 재실행하면 코드에 적힌 기존 출력 위치를 사용할 수 있으므로 재실행 전 별도 작업 복사본에서 경로를 수정하십시오.

## 대응 근거와 미확인 항목

Analyze.ipynb의 OUTPUT_DIR=ANALYZE, WavLM 노트북의 OUTPUT_DIR=ML_EXPERIMENT_T1_WAVLM_FROZEN_ELASTICNET, 재현 노트북의 HUBERT_PAPER_REPRODUCTION, Fusion/Selected3의 HUBERT_EGEMAPS_FUSION, eGeMAPS 분석 노트북의 EGEMAPS_GROUP_ANALYSIS, 최신 노트북의 HUBERT_ALS_7EXP_HPO를 결과 파일의 run_config·모델명·엑셀 시트와 대조했습니다.

Selected3는 20261112T011348_511305Z의 6개 구조, 이전 Fusion은 20261029의 두 실행과 연결했습니다. HuBERT 20261005T215051 실행은 CNN/MLP mean 일부만 있는 부분 실행으로, 완료된 추가 실험으로 세지 않았습니다. 제공된 풀링 결과에는 attention의 완료 결과가 없어 별도 실험으로 세지 않았습니다.

초기 추출, ML 1·2차, Data2Vec의 직접 생성 노트북은 제공 폴더에서 확인되지 않았습니다. 결과와 설정은 모두 보존하되 다른 노트북과의 직접 대응을 확정하지 않았습니다. Untitled0도 크기가 작다는 이유로 제외하지 않았습니다.

## 제외 범위

SAND_Challenge_task1_dataset.zip과 이름에 CACHE가 명시된 특징 캐시 트리, __pycache__를 복사하지 않았습니다. 결과 폴더에 저장된 scaler, normalization 배열, 환자 임베딩 내보내기, 모델, HPO DB는 실험 산출물로 보존했습니다. 캐시 내부 원자료는 내려받지 않았습니다.

## 검증 범위

2,137개 원본 파일을 목록화했습니다. 다운로드 가능한 2,135개는 원본 바이트의 SHA-256과 압축 후 각 멤버를 다시 읽은 SHA-256을 전수 비교했습니다. 모든 엑셀 7개의 88개 시트에 대해 저장된 셀 값과 수식을 주소별로 추출했고, ZIP 내부 모든 구성요소의 해시도 기록했습니다. csv의 stored_value는 원본 XML 표현이며 엑셀을 재작성하지 않았습니다. 문자열 테이블 등 모든 해석 정보는 원본 xlsx 안에 유지됩니다.

약 604MB인 Data2Vec best_model.pt/latest_model.pt 2개는 연결 도구의 256MB 다운로드 한도로 내용 해시를 독립 검증할 수 없어 Drive 서버 복사와 파일 크기 검증만 수행합니다. 따라서 이 두 파일에 대해서는 독립적인 바이트 단위 검증 완료를 주장하지 않습니다.

source_to_destination_manifest.csv/json에 원본 ID·경로·크기·해시·압축파일·멤버 경로가 있으며, archive_integrity.json과 excel_full_content_audit.json에 검증 증거가 있습니다. Drive 업로드 후 검증 결과는 최종 보고서에 추가됩니다.

## 큰 결과 묶음의 분할

100MB 업로드 한도에 맞춰 큰 CNN 실험 묶음을 part01 등의 독립 ZIP으로 나눴습니다. 각 ZIP을 같은 위치에 풀면 전체 경로가 합쳐집니다. 바이너리 분할 파일이 아니므로 별도 결합 명령은 필요하지 않습니다. 파일 이름과 멤버 경로는 manifest에 기록했습니다.

## 클라우드 검증의 구분

원본 바이트와 압축 후 멤버의 SHA-256은 2,135개 모두 전수 대조했습니다. Drive에 올라간 압축파일과 개별 복사본은 원격 메타데이터의 파일 크기와 대상 폴더를 확인합니다. 원격 압축파일 전체를 다시 다운로드한 SHA-256 검증은 실행 환경의 연결 장애로 수행하지 못했습니다. 최종 cloud_destination_verification.json에 수행한 검증과 범위를 명시합니다.

## 최종 대조 결과

원본 474개 폴더 재조회 결과, 대상 파일 2,137개의 누락·변경·추가 항목은 0개였습니다. 결과 압축 41개 모두 Drive 원격 파일 크기와 대상 폴더가 일치했습니다. 노트북·엑셀 개별 복사본 15개도 크기가 일치했습니다. 모든 원본 ID가 원격 압축 41개 또는 대용량 모델 복사본 2개에 연결됐습니다. 전체 목록과 다운로드 위치는 source_to_destination_manifest_with_links.json에 있습니다. 최종 감사 ZIP 자체는 업로드 후 크기를 별도로 확인합니다.
